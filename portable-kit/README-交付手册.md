# Claude 安全锁 · 极简双端交付手册（方案 A：严格白名单零泄露）

本交付包（`portable-kit/`）专为**零依赖、3 分钟快速交付**设计：无需 Xcode、无需编译、无需折腾复杂分流规则，**macOS（Stash / 小火箭 / Clash Verge / v2rayN）与 Windows（Clash Verge / v2rayN）全兼容**。

---

## 核心防护原理（为什么断网/重连/手机热点/VPS 掉线都不泄露？）

开启 **「🟢 安全锁」** 后，操作系统内核防火墙（macOS `pf` / Windows Defender Firewall）执行 **Fail-Closed 严格白名单**：
1. **只放行**：本机回环 + 代理 TUN 虚拟网卡 + 局域网/DHCP + **你配置的代理入口节点 IP**；
2. **其余全部 0 毫秒内核 DROP**：所有物理网卡（Wi-Fi / 有线 / 新插手机热点）的公网 IPv4、全部公网 IPv6（`2000::/3`）、WebRTC/STUN UDP 与物理网卡裸 DNS 53 端口一律丢弃；
3. **链式代理关键提醒**：如果你配了链式代理（`本机 → 第一跳入口中转 → 第二跳落地家宽`），白名单中填写 **第一跳入口节点的 IP（或域名）**！多个入口用英文逗号 `,` 隔开。如果填的是域名，工具会自动解析并写入托管 `hosts`，防止封死物理 DNS 后重连失败。

## 一、macOS 交付流程（3 步，约 2 分钟）

1. **配置代理客户端**（Stash / 小火箭 Shadowrocket / Clash Verge / v2rayN）：
   - 导入节点/链式代理配置；
   - 切换为 **全局模式（Global）**；
   - 确认开启 **TUN / 增强模式 / Fake-IP（`198.18.0.1`）**，关闭客户端内 IPv6。
2. **一键初始化环境**：
   - 将 `portable-kit/mac/` 放到客户电脑固定目录（如 `~/Documents/Claude安全锁/`）；
   - 双击 **`Claude安全锁控制台.command`**（首次若提示未验证开发者，右键 → 打开）；
   - 选择 **「⚙️ 一键初始化环境」** → 填入**第一跳代理入口 IP 或域名** → 输入一次开机密码；
   - 自动完成：识别出口国家、锁定时区、锁定地区格式、设置 Claude 桌面版为英文、关闭全接口 IPv6、写入入口 hosts 并开启 `pf` 内核安全锁。
   - *（可选）* 双击 **`创建桌面快捷App.command`**，在客户桌面生成一个「Claude安全锁」快捷图标，以后点一下直接弹出切换菜单。
3. **自检交机**：
   - 点 **「🔍 14维度深度体检」**，或点 **「📄 导出交机体检报告到桌面」** 生成脱敏验收凭证，确认核心项全部 `[✓]` 即可交机！

## 内置 14 维度深度本地体检清单（整合三大开源诊断项目）

本交付包内置零依赖 14 维度深度体检引擎（macOS `env-audit.py` / Windows `env-audit.ps1`），融合了 `TZZ520/claude-environment-check`、`betaer/AiSignalGuard` 与 `Nooobhh/claude-analysis` 的核心本地检测能力：

1. **防直连安全锁（pf / WFP）**：核验方案 A 白名单内核规则是否生效；
2. **全局 TUN 与默认路由**：核验默认路由是否走代理 TUN，揪出手机热点/物理网卡抢路由；
3. **本地 DNS 与大陆 DNS 信号**：审计系统 DNS 是否含 `114`/`223.5.5.5`/`119.29.29.29` 等大陆公共 DNS 与 `claude.ai` 解析；
4. **代理环境变量与 PAC 冲突（自动脱敏）**：检测遗留 `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY`/PAC；
5. **多源出口 IP 共识**：交叉比对 `ipinfo` / `ipwho.is` / `cloudflare` / `ipapi.is`，识别分流不一致；
6. **Anthropic 地区合规性**：拦截 CN / HK / MO / RU / BY / KP / IR / SY / CU 等不支持地区；
7. **IP 纯净度与 ASN 画像**：核对机房（Datacenter）/ 公开代理 / VPN / Tor / 滥用标记，缺失字段如实标未知；
8. **WebRTC / STUN 泄露探测**：并发向 4 组国内外 STUN 服务器探测 UDP 泄露（安全锁拦截时准确判定零泄露）；
9. **时区 / UTC 偏移 / 地区 / 语言一致性**：核对本机时区与出口国家匹配度及 Claude 客户端语言；
10. **全网卡 IPv6 封锁**：检查全部启用网卡 IPv6 与内核 `2000::/3` 封锁；
11. **Anthropic 多端点连通与延迟**：分别实测 `claude.ai`、`api.anthropic.com`、`platform.claude.com` 状态码与毫秒延迟；
12. **TLS 证书完整性与 MITM 劫持校验**：核验 TLS 协议版本、ALPN 与签发机构（识别 Charles/Fiddler/企业杀软劫持证书）；
13. **WebSocket 隧道能力**：验证 `wss://` Upgrade 握手；
14. **Claude 客户端与环境变量污染**：检查 Desktop/CLI 安装状态与 `ANTHROPIC_BASE_URL`/`ANTHROPIC_API_KEY` 等覆盖变量，并输出**证据覆盖率**。

## 二、Windows 交付流程（3 步，约 2 分钟）

1. **配置代理客户端**：
   - **Clash Verge**：先点「服务模式（Service Mode）」安装服务 → 打开 **TUN 模式** → 模式选 **全局（Global）**；
   - **v2rayN**：必须 **右键以管理员身份运行** → 勾选底部 **「启用 Tun」** → 路由选 **全局（Global）**。
2. **一键初始化环境**：
   - 将 `portable-kit/windows/` 放到客户电脑固定目录（如桌面或 `C:\ClaudeGuard\`）；
   - 双击 **`Claude安全锁控制台.bat`**（自动弹出管理员 UAC 授权，打开深色图形界面）；
   - 在顶部输入框填入 **第一跳代理入口 IP 或域名**（多个用逗号隔开）；
   - 点击蓝色按钮 **「⚙️ 一键初始化环境」** → 自动完成：识别出口国家、锁定 Windows 时区与地区、设置 Claude 桌面版（含 MSIX）为英文、关闭全网卡 IPv6、开启 Windows 防火墙精准白名单安全锁。
3. **自检交机**：
   - 点击 **「🔍 一键环境自检」**，确认全部 `[✓]` 即可交机！

## 三、客户日常怎么用？（一句话教给客户）

- **要用 Claude 时**：先打开代理客户端（确认全局 + TUN 已开）→ 双击 **「Claude安全锁控制台」** 点 **「🟢 开启安全锁」** → 放心打开 Claude 使用！
- **不用 Claude、想关代理正常刷国内网站时**：双击控制台点 **「🟡 恢复直连模式」** → 软件会自动先安全关闭 Claude 桌面版与 CLI，再瞬间解除防火墙锁，恢复正常直连上网！

## 四、常见问题速解

1. **开启安全锁后上不了网了？**
   - 99% 是因为填错了白名单入口 IP（链式代理填成了第二跳落地 IP，必须填**第一跳入口 IP**），或者代理客户端忘了开「全局 + TUN」。
   - 解决：点 **「🟡 恢复直连模式」** 立刻恢复网络，核对第一跳入口 IP 后重新保存并开启安全锁。
2. **客户改用手机热点给电脑开网，需要重新配置吗？**
   - **不需要！** 防火墙已放行 DHCP 拿 IP，且按非 TUN 源地址/接口无关方式拦截，插上手机热点自动拿 IP、自动封死热点公网 IPv6 与一切直连，代理自动通过热点重连第一跳节点。
3. **以后换了新节点 IP 怎么办？**
   - 先点 **「🟡 恢复直连模式」** → 在控制台里更新入口节点 IP → 再点 **「🟢 开启安全锁」**（如果换了国家，点一次「一键初始化环境」同步刷新时区与地区）。
