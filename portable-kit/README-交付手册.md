# Claude 持久化安全锁 · 双锁双端极简交付手册

本安装包专为 **零依赖、3 分钟快速交机、绝对防直连泄露** 设计：无需 Xcode、无需编译、无需配置复杂代理分流规则，**macOS（Stash / 小火箭 Shadowrocket / Clash Verge / v2rayN）与 Windows（Clash Verge / v2rayN）通用**。

---

## 核心双锁架构（断网 / 代理退出 / 软件被杀 / 死机重启均零直连泄露）

所有拦截规则全部写入 **操作系统内核防火墙**（macOS `pf` + 开机 `LaunchDaemon` 持久化；Windows Defender Firewall WFP 持久化策略），**不依赖后台驻留软件存活**。即便代理闪退、本工具退出、电脑死机重启或切到手机热点，内核防火墙依然生效。

### 🔒 锁 1：直连切换锁（日常随时切换，海外与 Claude 始终死锁）
无论切换到以下哪一档，**Claude 官方 ASN (`AS399358` / `160.79.104.0/21`)、动态解析的 Claude 生态域名 IP、一切海外公网 IPv4、全部公网 IPv6 (`2000::/3`) 与 WebRTC STUN 均被内核 0ms 丢弃**（Windows 端额外叠加 `Claude.exe` / `claude.exe` 进程出站硬锁）：

1. **🌐 国内直连放行模式（默认推荐）**：
   - 放行：本机回环 + 代理 TUN 虚拟网卡 + 局域网/DHCP + **第一跳代理入口节点** + **7,456 条权威中国大陆 IPv4 段**；
   - 死锁：Claude/Anthropic 全部 IP、全部海外公网 IPv4、公网 IPv6、STUN 端口；
   - **效果**：日常刷微信/国内网站直连丝滑流畅；**就算此时关了代理或不小心点开 Claude，请求也在内核被 0ms 掐死，绝不暴露本地直连 IP**！
2. **🛡️ 全封闭模式（最严格）**：
   - 仅放行本机回环 + 代理 TUN + 局域网/DHCP + **第一跳代理入口节点**，连国内公网直连和物理网卡裸 DNS 53 端口也一并拦截；
   - **效果**：除代理隧道外整机零公网直连，连本地 DNS 查询也全部强制进入代理 TUN。

### 🔐 锁 2：持久化硬锁总开关（彻底恢复原生系统）
- 只要未主动点此开关，持久化硬锁在**代理退出、本软件关闭、系统重启后依然永久生效**。
- 仅在 **明确确定不再使用 Claude** 时才手动打开本开关解除持久化硬锁；点击后会弹出 **强二次确认警示**，确认后软件自动先安全关闭 Claude Desktop 与 CLI 进程，再彻底清理所有内核防火墙规则、开机 `LaunchDaemon` 与托管 `hosts`，让电脑恢复到未使用软件前的原生状态。
- ⚠️ **切记：解开锁 2 之后，千万不要启动任何 Claude 桌面端、CLI 或网页服务！**

> **链式代理关键提醒**：若使用链式代理（`本机 → 第一跳中转入口 → 第二跳海外家宽落地`），白名单中务必填写 **第一跳入口节点的 IP（或域名）**！多个入口用英文逗号 `,` 隔开。

## 一、macOS 一键安装与交机（3 步，约 2 分钟）

1. **安装**：解压 `Claude安全锁-macOS安装包.zip`，右键点击根目录的 **`一键安装.command` → 打开**（首次放行未公证提示）。
   - 自动安装到 `~/.claude-guard/kit`，并在 `/Applications/` 与 **桌面** 生成 **`Claude安全锁.app`** 快捷图标，随后自动打开控制台。
2. **配置代理并一键初始化**：
   - 在 Stash / 小火箭 / Clash Verge / v2rayN 中导入节点，切换为 **全局模式（Global）** 并开启 **TUN / 增强模式 / Fake-IP（`198.18.0.1`）**，关闭代理内 IPv6；
   - 在控制台点 **「⚙️ 一键初始化环境」** → 填入**第一跳入口 IP 或域名** → 输入开机密码；
   - 自动完成：锁定时区与地区格式、设 Claude Desktop 为英文、关闭全网卡 IPv6、写入开机持久化 `LaunchDaemon` 并开启 **锁 1（国内直连放行 / 海外与 Claude 死锁）**。
3. **双验收交机**：
   - 点 **「🛡️ 验收操作系统防火墙与丢包日志」**：实证核验 `pfctl` 状态、开机 `LaunchDaemon` 与内核真实丢包计数；
   - 点 **「🔍 14维度深度体检」** / **「📄 导出交机体检报告到桌面」**：确认核心项全绿即可交机！

> 彻底卸载：双击解压包中的 **`卸载.command`**（自动先解开锁 2 恢复原生网络，再清理全部应用和配置）。

## 二、Windows 一键安装与交机（3 步，约 2 分钟）

1. **安装**：先将 `Claude安全锁-Windows安装包.zip` **右键 → 全部解压缩**，再双击根目录的 **`一键安装.bat`**（自动 UAC 提权）。
   - 自动安装到 `C:\ProgramData\ClaudeGuard`，在 **桌面** 生成 **`Claude安全锁`** 快捷方式，并自动打开图形控制台。
2. **配置代理并一键初始化**：
   - **Clash Verge**：安装并启用 **服务模式（Service Mode）** → 打开 **TUN 模式** → 选择 **全局（Global）**；
   - **v2rayN**：**右键以管理员身份运行** → 勾选底部 **「启用 Tun」** → 路由选 **全局（Global）**；
   - 在控制台顶部填入 **第一跳代理入口 IP 或域名**，点 **「⚙️ 一键初始化环境」**；
   - 自动锁定 Windows 时区/地区、设置 Claude 桌面版（含 MSIX）为英文、关闭全网卡 IPv6、开启三档防火墙拦截日志并写入持久化 WFP 安全锁（默认锁 1：国内直连放行 / 海外与 Claude 死锁）。
3. **双验收交机**：
   - 点 **「🛡️ 验收防火墙与日志」**：核验 Domain/Private/Public 三档防火墙状态、规则分类数，并直接拉取 `%SystemRoot%\System32\LogFiles\Firewall\pfirewall.log` 最近 `DROP` 丢包记录；
   - 点 **「🔍 14维度深度体检」** / **「📄 导出交机报告到桌面」**：确认核心项通过即可交机！

> 彻底卸载：双击解压包中的 **`卸载.bat`**（自动先解开锁 2 恢复原生防火墙与网络，再删除全部安装文件）。

## 三、如何实测验证「断网 / 退代理 / 退软件绝不泄露」？

1. 确认已开启 **锁 1**（任意模式）；
2. **完全退出代理客户端**，并 **关闭 Claude安全锁控制台**；
3. 打开终端/命令提示符测试直连：
   - 测试访问国内 IP（`lock-cn` 模式下可通）：`curl -I --max-time 3 https://www.baidu.com`
   - 测试直连 Claude / 海外 IP（必须被内核 0ms 拒绝或超时）：`curl -I --max-time 3 https://claude.ai` 与 `curl -I --max-time 3 https://160.79.104.10`
4. 重新打开控制台点击 **「🛡️ 验收防火墙与日志」**：
   - **macOS**：可见 `pfctl -a com.claude-guard -sr -v` 中 `block drop out log quick` 规则的 `Packets` 丢包计数真实递增；也可用 `sudo tcpdump -n -e -ttt -i pflog0` 实时抓包查看被内核拦截的数据包；
   - **Windows**：可见 `pfirewall.log` 中出现发往 `160.79.104.x` 或海外 IP 的 `DROP` 日志条目。

## 四、内置 14 维度深度本地体检清单

融合了 `TZZ520/claude-environment-check`、`betaer/AiSignalGuard` 与 `Nooobhh/claude-analysis` 的核心本地检测能力：

1. **持久化硬锁与开机自启/拦截日志状态**（macOS `pf` + `LaunchDaemon` / Windows WFP + `LogBlocked`）；
2. **全局 TUN 与默认路由归属**（揪出手机热点或物理网卡抢占默认路由）；
3. **本地 DNS 与大陆 DNS 信号**（审计 `114`/`223.5.5.5`/`119.29.29.29` 及 `claude.ai` 解析）；
4. **代理环境变量与 PAC 冲突**（自动脱敏账号密码）；
5. **多源出口 IP 共识**（交叉比对 `ipinfo` / `ipwho.is` / `cloudflare` / `ipapi.is`）；
6. **Anthropic 地区合规性**（拦截 CN/HK/MO/RU/BY/KP/IR/SY/CU 等受限区）；
7. **IP 纯净度与 ASN 画像**（机房/代理/VPN/Tor/滥用标记，未知不冒充通过）；
8. **WebRTC / STUN 泄露探测**（4 组国内外 STUN 服务器 UDP 探测）；
9. **时区 / UTC 偏移 / 地区 / 语言一致性**；
10. **全网卡 IPv6 封锁**；
11. **Anthropic 多端点连通与延迟**（`claude.ai`、`api.anthropic.com`、`platform.claude.com`）；
12. **TLS 证书完整性与 MITM 劫持校验**；
13. **WebSocket 隧道握手校验**；
14. **Claude 客户端与环境变量污染检测** + 综合 **证据覆盖率**。
